# Agent Instructions — Protocol Emulator ASIC (Jane Street Competition)

## Project context
- Jane Street "Protocol Emulator ASIC" competition: a small **programmable** processor core whose ISA is designed for reading/writing pins and cycle-accurate timing, so protocols (UART, SPI, I2C, ...) are implemented in *firmware*, not fixed logic.
- Reference architectures: RP2040 PIO state machines, TI Sitara PRU cores.
- Process: IHP 130nm CMOS5L via Tiny Tapeout. Budget: **6x4 tiles ≈ 24K logic cells** (leave headroom for clock-tree buffers and routing).
- Deadline: 18 Jan 2027. Target: March 2027 CMOS5L shuttle.
- Submission must be open source.

## Hard constraints (Tiny Tapeout)
- Top module name must start with `tt_um_` (include a unique username suffix).
- Pin interface: `ui_in[7:0]`, `uo_out[7:0]`, `uio_in[7:0]`, `uio_out[7:0]`, `uio_oe[7:0]`, `ena`, `clk`, `rst_n`. All outputs must be assigned (tie unused to 0).
- `ena` is always 1 when powered — safe to ignore.
- Keep `info.yaml` `source_files` in sync with `test/Makefile` `PROJECT_SOURCES`.
- Set `tiles: "6x4"` in `info.yaml` for this competition.

## Verilog style
- Synthesizable RTL only in `src/`. Use `always @(posedge clk)` with async reset (`rst_n`) where needed.
- No latches: fully specify all `case`/`if` branches (use `default`).
- Use `wire`/`reg` with explicit widths; avoid implicit nets.
- List unused inputs in an `_unused` reduction to suppress warnings.
- One module per file, file named after the module.

## Verification (explicitly scored by the competition)
- cocotb 2.x + Icarus Verilog. Testbench wrapper is `test/tb.v`, tests in `test/test.py`.
- Prefer protocol-level checkers (bit-accurate UART/SPI/I2C framing) over raw pin asserts.
- Use constrained-random stimulus for protocol tests; keep deterministic regression tests for core ISA.
- Run `cd test; make -B` after any RTL change. Waveform: `gtkwave tb.fst tb.gtkw`.

## Area discipline
- Run synthesis early and often; check mapped cell count against the ~24K budget.
- SRAM is more area-efficient than flip-flops for instruction memory (see Tiny Tapeout SRAM examples).
- A design that fits after synthesis can still fail to route or meet timing — run the full P&R flow before declaring done.

## Environment (Windows)
- Run `. .\setup-env.ps1` before `make` (sets up venv, MSYS2 sh, iverilog, ezwinports make).
- Do not commit `.venv/`, `test/sim_build/`, `results.xml`, `*.fst` (already gitignored).
